# robloxgame

Rojo синхронизирует файлы `src` с уже открытой игрой Quiet Cove v5.
В проекте управляются каталог рыб, PNG-портреты и их показ после 3D-анимации.
Карта и остальные игровые модули остаются в существующей игре.

- `src/shared` — каталог рыб, настройки, геометрия удочки и команды просмотра.
- `src/client` — анимации, карточка улова, рюкзак и бестиарий.
- `src/client/CatchArtData` — 19 встроенных PNG-портретов.
- `src/client/SahurArtData.luau` — отдельный существующий портрет Сахура.
- `src/server` — точечное удаление модели Капуччино Ассассино при запуске сервера.
- `assets/portraits` — предоставленные исходные PNG.
- `tools/encode_portraits.py` — преобразование PNG в игровые модули.

Все 20 активных рыб имеют PNG-портрет. Капуччино Ассассино (`cappuccino`)
удалён из каталога и выпадения. Балерина Капуччина (`ballerina`) сохранена.
Старые записи удалённого вида отфильтровываются существующей загрузкой профиля.
Метаданные папок Rojo сохраняют остальные экземпляры игры.

Инструкция и названия PNG находятся в [assets/portraits/README.md](assets/portraits/README.md).
Конвертер запускается из корня проекта после получения исходных файлов.
Для обновления останови Play, выполни Fetch/Pull в GitHub Desktop,
дождись синхронизации Rojo и заново запусти Play. При изменении
`default.project.json` перезапусти `rojo serve default.project.json`
и подключись к нему в Studio.
