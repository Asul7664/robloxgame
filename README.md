# robloxgame

Rojo синхронизирует этот проект с уже открытым файлом
`QuietCove_10_Brainrots_v6_portraits_patched.rbxlx`.
В проекте управляются каталог рыб, PNG-портреты, их показ после 3D-анимации,
карта островов, русские подписи и ежедневные/еженедельные задания.

- `src/shared` — каталог рыб, настройки, геометрия удочки и команды просмотра.
- `src/client` — анимации, карточка улова, рюкзак и бестиарий.
- `src/client/CatchArtData` — 19 встроенных PNG-портретов.
- `src/client/SahurArtData.luau` — отдельный существующий портрет Сахура.
- `src/client/ThumbnailArt.luau` — атлас иконок всех 20 активных рыб из v6.
- `src/server` — существующий сервер игры и сохранение профилей, перенос островов
  и точечное удаление модели Капуччино Ассассино при запуске сервера.
- `assets/portraits` — предоставленные исходные PNG.
- `tools/encode_portraits.py` — преобразование PNG в игровые модули.
- `world-text.project.json` — правильные русские надписи и тексты взаимодействия.

Все 20 активных рыб имеют PNG-портрет. Капуччино Ассассино (`cappuccino`)
удалён из каталога и выпадения. Балерина Капуччина (`ballerina`) сохранена.
Старые записи удалённого вида отфильтровываются существующей загрузкой профиля.
Метаданные папок Rojo сохраняют остальные экземпляры игры.

В v6 сохранены 40 повреждённых текстовых свойств карты: русские UTF-8 строки
были прочитаны как Latin-1. `world-text.project.json` задаёт исправленные
`Text`, `ActionText` и `ObjectText` существующих объектов. Надписи обновляются
при синхронизации в режиме редактирования. Для изменения подписи отредактируй
её строку в этом файле и сохрани JSON в UTF-8; Rojo подхватит изменение.

Инструкция и названия PNG находятся в [assets/portraits/README.md](assets/portraits/README.md).
Конвертер запускается из корня проекта после получения исходных файлов.
Для получения этого обновления:

1. Останови Play и выполни Fetch/Pull в GitHub Desktop в ветке `codex/quiet-cove-download`.
2. Перезапусти `rojo serve default.project.json` из корня репозитория:
   обновился состав синхронизируемых объектов.
3. Подключись к серверу через плагин Rojo в Studio и примени синхронизацию.
4. Проверь надписи в открытой v6, затем запусти Play для проверки портретов.

Последующие изменения текста и скриптов подхватываются работающим Rojo.
После изменения клиентских скриптов останови и заново запусти Play.

Острова и причалы автоматически переезжают на новые координаты при запуске
Play. Существующие модели перемещаются целиком, сохраняя внутреннее расположение
деталей; повторный запуск не сдвигает их ещё раз. Риф расположен примерно
в 790 studs от бухты, Мшистый остров и Лагуна — в 1660, Пески — в 1980,
Штормовые скалы — в 2270. Границы моря и масштаб карты увеличены соответственно.
Чтобы увидеть расположение и сохранить его в режиме редактирования, после
синхронизации можно выполнить в Command Bar:

```lua
local s = game.ServerScriptService.QuietCove
require(s.Archipelago).Attach(require(s.World).Build())
```

На рифе чаще встречаются Бобрито, Триппи Троппи и Бомбардиро. Патапим и
Амбалабу там редки, а Мшистый остров остаётся основным местом их ловли.
Пески специализируются на Сахуре, Лирили и Фриго Камело; Лагуна — на Балерине
и Чимпанзини, ночью также на Тралалеро. Штормовые скалы — на Гигачаде,
а ночью там встречаются Верити и Ла Вакка. Числа `Weights` являются весами,
а итоговые проценты зависят от удочки, времени суток и доступных видов.

Кнопка **ЗАДАНИЯ** открывает два набора по пять заданий:

- Ежедневные: 60–80 любых уловов, два вида по 10–14 штук, 25–35 уловов
  на указанном острове и 20 минут активной рыбалки.
- Еженедельные: 200–260 любых уловов, два вида по 40–60 штук, 90–120 уловов
  на указанном острове и 120 минут активной рыбалки.

Один улов может продвигать сразу несколько заданий. Виды и остров выбираются
из доступных игроку по уровню, удочке и наличию лодки; задания не требуют
ночных или мифических существ. Набор фиксируется до сброса, поэтому выход
из игры или покупка улучшения не меняют уже выданные задания.
Награды за весь набор составляют 660–1650 монет в день и 3000–6500 в неделю,
в зависимости от качества удочки при выдаче. Кнопка **ЗАБРАТЬ** выдаёт награду
один раз. Продажа рыб сохраняет прогресс заданий.

День обновляется в 00:00 UTC, неделя — в понедельник в 00:00 UTC.
Таймер в окне показывает оставшееся время; сброс работает и во время игры.
Активность считает сервер во время рыбалки; стояние без заброса и поездки
на лодке не засчитываются. Все пять ежедневных заданий требуют минимум
20 минут активной рыбалки; продажи, путешествия и анимации улова увеличивают
общее время игры. Время меняется в `Config.Quests`, цели и награды — в
`src/shared/Quests.luau`.

Прогресс и отметки полученных наград сохраняются в прежнем профиле вместе
с монетами и уловом, без смены DataStore. В опубликованной игре сохраняются
между входами. Для обычного локального Play остаётся `SaveInStudio = false`:
тестовый прогресс исчезает после остановки. При включении `SaveInStudio`
используется отдельное хранилище с суффиксом `_TEST`.

Обе руки следуют общему сглаженному положению удочки во время рыбалки.
В `Idle` и при ходьбе работает обычная анимация персонажа.
Скорость заброса задаётся в `src/shared/Config.luau`, в `Config.Casting`:
`WindupSeconds` — короткая подготовка, `SwingSeconds` — момент выпуска,
`StrokeEndSeconds` — конец маха, `SettleSeconds` — возврат в положение ожидания.
Текущие значения: 0.10 / 0.24 / 0.42 / 0.74 секунды. Эти времена должны
идти по возрастанию. Леска при успешном улове переходит от поплавка к
движущейся 3D-модели рыбы и убирается после завершения вытягивания.
Даже короткое нажатие показывает замах. Пересечение прямоугольных габаритов
рук с телом у нестандартного MeshPart-аватара больше не отключает хват:
коррекция выбирает положение локтей, сохраняя обе кисти на удочке.
Проверка самой удочки на пересечение с телом продолжает работать.
Оба плеча остаются на штатных креплениях аватара; правый локоть использует
зеркальное направление левого. Правая точка хвата `CastMainGrip` расположена
на `Y = -0.15`, левая `CastSupportGrip` — на `Y = 0.25` относительно рукоятки.
Правая кисть немного приближена к левой вдоль удочки. Обе кисти пересчитываются
относительно одной удочки; при ходьбе и в `Idle` обычная поза восстанавливается.
При зарядке и забросе обе ноги целиком сохраняют положение относительно
персонажа: бёдра, колени и ступни. При переходе к ожиданию поклёвки
блокировка снимается.

Для просмотра хвата и заброса нажми Play, возьми удочку и запускай команды
по одной в Command Bar:

```lua
require(game.ReplicatedStorage.QuietCove.StudioPreview):Rod("Waiting", 6)
require(game.ReplicatedStorage.QuietCove.StudioPreview):Rod("Reeling", 6)
require(game.ReplicatedStorage.QuietCove.StudioPreview):Rod("Casting", 3)
require(game.ReplicatedStorage.QuietCove.StudioPreview):Catch("capybara")
require(game.ReplicatedStorage.QuietCove.StudioPreview):Stop()
```

Проверки запускаются из корня проекта с установленным Lune:

```sh
lune run tests/island_balance.luau
lune run tests/quests.luau
lune run tests/quest_server.luau
lune run tests/quest_ui.luau
```

Для проверки переноса реального сохранённого мира первой команде можно передать
путь к исходному v6 `.rbxlx`. Проверки используют реальные игровые модули,
заменяя сервисы Roblox и экземпляры мира тестовыми объектами; внешний вид
и управление дополнительно проверяются в Studio.
