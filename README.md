# robloxgame

Rojo синхронизирует файлы `src` с уже открытой игрой Quiet Cove v5.
Карта, модели и остальные игровые модули сохраняются в существующей игре.

- `src/shared` — общие настройки и геометрия удочки.
- `src/client` — поза рук и эффекты заброса.
- `src/client/CatchArtData` — встроенные фотографии новых рыб.
  Метаданные папки сохраняют старые портреты при синхронизации.
- `assets/portraits` — предоставленные исходные PNG.
- `tools/encode_portraits.py` — преобразование PNG в игровые модули.

Инструкция и названия PNG находятся в [assets/portraits/README.md](assets/portraits/README.md).
Конвертер запускается из корня проекта после получения исходных файлов.
После обновления через GitHub Desktop останови и заново запусти Play.
