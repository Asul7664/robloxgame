# robloxgame

Rojo синхронизирует этот проект с уже открытым файлом
`QuietCove_10_Brainrots_v6_portraits_patched.rbxlx`.
В проекте управляются каталог рыб, PNG-портреты, их показ после 3D-анимации
и русские подписи персонажей на карте.

- `src/shared` — каталог рыб, настройки, геометрия удочки и команды просмотра.
- `src/client` — анимации, карточка улова, рюкзак и бестиарий.
- `src/client/CatchArtData` — 19 встроенных PNG-портретов.
- `src/client/SahurArtData.luau` — отдельный существующий портрет Сахура.
- `src/client/ThumbnailArt.luau` — атлас иконок всех 20 активных рыб из v6.
- `src/server` — точечное удаление модели Капуччино Ассассино при запуске сервера.
- `assets/portraits` — предоставленные исходные PNG.
- `tools/encode_portraits.py` — преобразование PNG в игровые модули.
- `world-text.project.json` — правильные русские надписи и тексты взаимодействия.

Все 20 активных рыб имеют PNG-портрет. Капуччино Ассассино (`cappuccino`)
удалён из каталога и выпадения. Балерина Капуччина (`ballerina`) сохранена.
Старые записи удалённого вида отфильтровываются существующей загрузкой профиля.
Метаданные папок Rojo сохраняют остальные экземпляры игры.

В v6 сохранены 40 повреждённых текстовых свойств карты: русские UTF-8 строки
были прочитаны как Latin-1. `world-text.project.json` задаёт исправленные
`Text`, `ActionText` и `ObjectText` существующих объектов. Надписи обновляются
при синхронизации в режиме редактирования. Для изменения подписи отредактируй
её строку в этом файле и сохрани JSON в UTF-8; Rojo подхватит изменение.

Инструкция и названия PNG находятся в [assets/portraits/README.md](assets/portraits/README.md).
Конвертер запускается из корня проекта после получения исходных файлов.
Для получения этого обновления:

1. Останови Play и выполни Fetch/Pull в GitHub Desktop в ветке `codex/quiet-cove-download`.
2. Перезапусти `rojo serve default.project.json` из корня репозитория:
   обновился состав синхронизируемых объектов.
3. Подключись к серверу через плагин Rojo в Studio и примени синхронизацию.
4. Проверь надписи в открытой v6, затем запусти Play для проверки портретов.

Последующие изменения текста и скриптов подхватываются работающим Rojo.
После изменения клиентских скриптов останови и заново запусти Play.

Обе руки следуют общему сглаженному положению удочки во время рыбалки.
В `Idle` и при ходьбе работает обычная анимация персонажа.
Скорость заброса задаётся в `src/shared/Config.luau`, в `Config.Casting`:
`WindupSeconds` — короткая подготовка, `SwingSeconds` — момент выпуска,
`StrokeEndSeconds` — конец маха, `SettleSeconds` — возврат в положение ожидания.
Текущие значения: 0.10 / 0.24 / 0.42 / 0.74 секунды. Эти времена должны
идти по возрастанию. Леска при успешном улове переходит от поплавка к
движущейся 3D-модели рыбы и убирается после завершения вытягивания.
Даже короткое нажатие показывает замах. Пересечение прямоугольных габаритов
рук с телом у нестандартного MeshPart-аватара больше не отключает хват:
коррекция выбирает положение локтей, сохраняя обе кисти на удочке.
Проверка самой удочки на пересечение с телом продолжает работать.
Правая рука ориентируется от реального плеча, с локтем вперёд и наружу.
При зарядке и забросе обе ноги целиком сохраняют положение относительно
персонажа: бёдра, колени и ступни. При переходе к ожиданию поклёвки
блокировка снимается.

Для просмотра хвата и заброса нажми Play, возьми удочку и запускай команды
по одной в Command Bar:

```lua
require(game.ReplicatedStorage.QuietCove.StudioPreview):Rod("Waiting", 6)
require(game.ReplicatedStorage.QuietCove.StudioPreview):Rod("Reeling", 6)
require(game.ReplicatedStorage.QuietCove.StudioPreview):Rod("Casting", 3)
require(game.ReplicatedStorage.QuietCove.StudioPreview):Catch("capybara")
require(game.ReplicatedStorage.QuietCove.StudioPreview):Stop()
```
