# Фотографии новых рыб

Подключены все 10 загруженных изображений. Файлы переименованы по игровым ID;
байты исходных PNG сохранены. Соответствие рыбам:

| Файл | Рыба |
| --- | --- |
| `floppa.png` | Флоппа-карась |
| `chipichapa.png` | Чипи Чапа |
| `bobrito.png` | Бобрито Бандито |
| `trippitroppi.png` | Триппи Троппи |
| `bombombini.png` | Бомбомбини Гусини |
| `lirili.png` | Лирили Ларила |
| `chimpanzini.png` | Чимпанзини Бананини |
| `frigocamelo.png` | Фриго Камело |
| `lavacca.png` | Ла Вакка Сатурно Сатурнита |
| `verity.png` | Верити — жёлтый шар со смайлом |

Капуччино Ассассино (`cappuccino`) удалён по запросу пользователя.
Балерина Капуччина (`ballerina`) сохранена вместе с её существующим PNG.
Десять исходных игровых портретов тоже перенесены в `src`: девять модулей
в `CatchArtData` и отдельный `SahurArtData.luau`. Всего у 20 активных рыб есть PNG.
Имя нового PNG должно совпадать с ID рыбы.

Подготовленные игровые картинки взяты прямо из предоставленной v6:
11 модулей портретов (эти 10 рыб и Гигачад) перенесены без изменений.
Все они содержат прозрачность; исходные PNG в этой папке сохранены как были.
Также перенесён атлас иконок всех 20 активных рыб из v6. Изображения,
исключённые пользователем через `.gitignore`, сохраняют прежние портреты.

Для обновления портретов после добавления PNG запусти конвертер из корня проекта:

```powershell
py -m pip install pillow
py tools/encode_portraits.py
```

Конвертер сохраняет импортированные модули v6, пока соответствующие исходные
PNG не изменились. Обычный запуск сейчас ничего не перезаписывает.
Чтобы заменить портрет, замени PNG с нужным ID и запусти конвертер.
Он создаёт `src/client/CatchArtData/<id>.luau` в том же формате, который
используют существующие фотографии. Новая картинка помещается на полотно 320×320
с сохранением пропорций; RGB кодируется палитрой 256 цветов, альфа отдельно.
Rojo переносит эти модули в `StarterPlayerScripts → CatchArtData`.
Метаданные этой папки сохраняют все старые портреты.
`portrait-manifest.json` содержит соответствия, размеры, SHA256 исходников
и модулей, а также происхождение импортированных картинок. У Гигачада нет
отдельного исходного PNG в репозитории: сохраняется его модуль из v6.
Если импортированный модуль отсутствует или изменён вручную, конвертер
сообщит об этом до записи файлов.

Скрипты отображения находятся в `src/client`. После завершения 3D-анимации
появляется карточка с кругом редкости, PNG, названием, весом, ценой и опытом.
PNG имеет приоритет перед 3D-портретом. В рюкзаке и бестиарии тоже используются
фотографии. Roblox asset ID не нужен.

После Pull останови и заново запусти Play. Для проверки в Command Bar:

```lua
require(game.ReplicatedStorage.QuietCove.StudioPreview):Catch("lirili")
require(game.ReplicatedStorage.QuietCove.StudioPreview):All("catch")
```

`Catch` показывает 3D-анимацию, затем PNG-карточку. `All("catch")` последовательно
показывает всех активных рыб. `Portrait("trippitroppi")` открывает только карточку,
`World("trippitroppi")` — только 3D-анимацию; `Stop()` останавливает просмотр.
