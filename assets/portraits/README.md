# Фотографии новых рыб

Положи сюда исходные PNG и отправь их в ту же ветку GitHub.

- `trippitroppi.png` — рыба-кот с усиками, присланная в чат.
- `lavacca.png` — корова с кольцом, присланная ранее.

Другие поддержанные ID: `floppa`, `chipichapa`, `bobrito`, `bombombini`,
`cappuccino`, `lirili`, `chimpanzini`, `frigocamelo`, `verity`.
Имя файла должно совпадать с ID. Исходные картинки остаются без изменений.
Прозрачность сохраняется; чёрный фон в самих пикселях не удаляется.

Изображения добавляются только из предоставленных PNG-файлов. Если файлов
нет, конвертер не создаёт портреты. Картинки из сообщений чата не подменяются
сгенерированными или тестовыми изображениями.

После получения PNG запускается конвертер из корня проекта:

```powershell
py -m pip install pillow
py tools/encode_portraits.py
```

Он создаёт `src/client/CatchArtData/<id>.luau` в том же формате, который
используют существующие фотографии. Картинка помещается на полотно 320×320
с сохранением пропорций; RGB кодируется палитрой 256 цветов, альфа отдельно.
Rojo переносит эти модули в `StarterPlayerScripts → CatchArtData`.
Метаданные этой папки сохраняют все старые портреты.

В существующей игре v5 новый PNG имеет приоритет перед 3D-портретом,
используется в карточке улова, рюкзаке и бестиарии. Roblox asset ID не нужен.
Остальные скрипты отображения уже входят в v5.

После Pull останови и заново запусти Play. Для проверки в Command Bar:

```lua
require(game.ReplicatedStorage.QuietCove.StudioPreview):Portrait("trippitroppi")
require(game.ReplicatedStorage.QuietCove.StudioPreview):Catch("lavacca")
```
