# Песчаное дно и подводные сады

`Workspace.QuietCoveSeabed` содержит песчаную поверхность всего океана
5600×5600 studs и группы рифов около шести островов. Глубина 10–26 studs;
возле бухты перепад составляет около 11 studs на небольшом участке. Это
статический рельеф с заметными грядами и впадинами, а не анимация движения песка.

`Sand` — непрерывная поверхность из 5056 физических клиньев с материалом Sand.
Вблизи островов размер ячейки около 64 studs, вдали — около 256. На границах
мелкой и крупной сетки высоты согласованы; толщина направлена вниз. Перепады остаются
в существующем водном объёме −28…0. Дно не пересекает корпуса лодок, лестницы,
игровые поверхности островов и причалы. Генератор не очищает и не перезаписывает
Terrain, не перемещает существующие объекты.

`ReefGardens` — 108 крупных участков шести разных типов: коралловые сады,
каменные гряды с арками и раковинами, колонии губок, морские веера,
заросли ламинарии и коралловые террасы. Это разные композиции и силуэты,
а не перекрашенные копии одного набора. Каждый остров получает все шесть типов
по три раза; перед пирсом бухты есть плотный пояс из всех шести.
Участки шириной около 18–28 studs стоят на фактической поверхности дна.
3510 деталей декора закреплены, без столкновений/touch/query; нет скриптов
обновления или внешних asset ID. Крупные формы находятся у островов, а не
равномерно распределяются по пустому морю. В Explorer у участка есть `ReefType`.

Вода немного прозрачнее (`VisualTheme.Water.WaterTransparency=0.42`), чтобы
сохранять видимость дна. Песок под ногами глубоко под водой не сбрасывает
30-секундный таймер акулы; сухая палуба и настоящий SeatPart безопасны.

## Как увидеть и сохранить вне Play

После Pull и синхронизации Rojo новые объекты создаются при следующем Play.
Для постоянного просмотра в редакторе остановите Play и выполните в Command Bar:

```lua
require(game.ServerScriptService.QuietCove.OceanStudio).Build()
```

Затем **Ctrl+S**. Команда использует свежие копии модулей и обходит старый кэш
редактора. Объекты сохраняются в текущем месте Studio; Rojo не управляет этой
моделью напрямую. Повторная сборка без изменений не создаёт дубли.
Обычный `WorldVisuals.ApplyAll()` также создаёт дно и рифы; новая команда удобна,
если этот модуль раньше уже был загружен в редакторе.

## Настройки

В `src/shared/Config.luau` находится `Config.Seabed`:

- `Enabled=true` — создание дна и рифов;
- `CellSize=256` — размер ячейки рельефа (допустимый диапазон 128–512);
- `DetailCellSize=64` — ячейка около островов (48–128);
- `DetailRadius=200` — ширина области мелкой сетки за радиусом острова (100–300);
- `MinDepth=10`, `MaxDepth=26` — глубины; ограничения 10–26 сохраняют воду над дном;
- `ReefPatchesPerIsland=18` — количество крупных участков у острова, максимум 24.

После обновления повторите команду Build вне Play: новая версия заменяет старое
плоское дно и редкие одинаковые сады. Старый кэш редактора этому не мешает.

Высота воды берётся из `Config.Ocean.SurfaceY`. Изменения настроек/версии/координат
островов пересобирают принадлежащую генератору модель. Объекты с таким же именем,
но без `QCOceanFloor`, не заменяются. Ручные правки внутри генерируемой модели
сохраняются до следующей пересборки с изменёнными параметрами.

Проверки запускаются из корня репозитория:

```sh
lune run tests/ocean_floor.luau
lune run tests/reef_scenery.luau
lune run tests/ocean_studio.luau
lune run tests/island_balance.luau
lune run tests/visual_theme.luau
lune run tests/water_hazard.luau
rojo build default.project.json -o /tmp/quiet-cove-ocean.rbxlx
```

Проверены настоящие Roblox CFrame/Instance, геометрия верхних граней, стыки,
размещение рифов и сохранение сцены. Lune не симулирует Studio water shader,
плавучесть лодок или физику плавания. В Studio проверьте вид дна из воды/с причала,
прохождение лодок у берега и работу акулы при погружении на песок.

Предпросмотр реальной геометрии (свет Blender приблизительный):

```sh
lune run tools/preview_ocean.luau /workspace/outputs/ocean-v2.json
blender -b -t 6 --python-exit-code 1 --python tools/preview_ocean.py -- /workspace/outputs/ocean-v2.json /workspace/outputs/ocean-v2
python tools/preview_ocean.py --compose /workspace/outputs/ocean-v2 /workspace/outputs/ocean-v2-preview.png
```
